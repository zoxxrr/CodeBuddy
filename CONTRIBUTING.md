# Contributing

Thanks for helping improve CodeBuddy.

1. Open an issue describing the change or bug before major work.
2. Keep changes focused and use descriptive names.
3. Do not add source-code comments unless a future contributor-facing need clearly justifies them.
4. Add tests for learning evaluation, rewards, authentication, and persistence changes.
5. Run `npm run check` and `npm test`.
6. Never commit secrets, database files, or real learner data.
7. Keep curriculum content accurate to current Luau and Roblox documentation.

By contributing, you agree that your contributions are provided under the MIT License.
